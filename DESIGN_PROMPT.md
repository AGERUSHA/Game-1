# Промпт: завершить дизайн EDU AI

Ты — senior product designer (UI/UX) и фронтенд-верстальщик. Нужно **завершить дизайн** существующей образовательной платформы **EDU AI**. Дизайн-система и основные экраны уже есть. **Не переделывай стиль с нуля** — продолжай его: те же цвета, шрифты, радиусы, тени, маскот и тон. Бэкенд сейчас не трогаем: нужен только законченный, единый и аккуратный внешний вид всех экранов и всех их состояний.

## 1. О продукте

- **EDU AI** — платформа для студентов вуза: курсы, материалы, тесты, задания, AI-помощник и геймификация (XP, уровни, серии дней, лиги, достижения).
- **Роли:** студент, преподаватель, администратор. У каждой роли свой кабинет с боковым меню.
- **Языки:** русский (основной), казахский, английский. Казахские слова длиннее — вёрстка должна это выдерживать.
- **Темы:** светлая, тёмная и «как в системе».
- **Аудитория:** студенты 17–25 лет, преподаватели. Тон дружелюбный и мотивирующий, но не детский.
- **Технология:** ASP.NET Core MVC (Razor `.cshtml`) + свой CSS (`edu.css`, `game.css`, `owl.css`, `landing.css`) + иконки Lucide. Без Bootstrap и Tailwind. Результат должен легко переноситься в Razor-разметку и CSS-классы.

**Остальное:**

- **Радиусы:** 8 / 10 / 14 (основной) / 18 / 24 px, у таблеток 999.

**Существующие компоненты (переиспользовать, не изобретать заново):**

**Маскот — сова «Ух».** Фиолетовая SVG-сова с настроениями: моргает, радуется, ликует, грустит, нервничает, думает, спит, фокусируется, стесняется (закрывает глаза крыльями, когда вводят пароль), подглядывает. С ростом уровня студента у неё появляются аксессуары: 3 — очки, 5 — шарф, 8 — медаль, 12 — стопка книг, 16 — золотая шапка. Ух появляется в пустых состояниях, на ошибках, в онбординге и при наградах, говорит репликами в «пузыре». Не перебарщивать: максимум одна сова на экран.

## 4. Задача А — довести КАЖДЫЙ существующий экран

Для каждого экрана из раздела 3 нарисуй и проверь:

1. **Все состояния:**
   - **Пустое:** нет данных вообще, а не только «ничего не найдено». Ух + одна фраза + кнопка действия. Примеры: «Пока нет курсов → Найти курс», «Ещё нет студентов → Пригласить», «Заданий нет — можно отдохнуть 🎉».
   - **Загрузка:** скелетоны (серые блоки) на месте карточек, таблиц и графиков, а не спиннер на весь экран.
   - **Ошибка загрузки:** блок в карточке «Не удалось загрузить» + «Повторить».
   - **Успех и подтверждения:** toast, а для опасных действий — модалка подтверждения.
   - **Disabled, hover, focus, active** для всех интерактивных элементов.
2. **Ошибки в полях форм:** красная рамка у поля + текст под ним (а не только общая плашка сверху), подсказки при вводе, счётчик символов, где есть лимит.
3. **Адаптивность:** 375 (телефон), 768 (планшет), 1280+ (компьютер). На телефоне боковое меню выезжает, таблицы превращаются в карточки, кнопки становятся во всю ширину, кликабельные зоны не меньше 44×44.
4. **Тёмная тема** на каждом экране: контраст, графики, тени, обложки курсов.
5. **Казахский язык:** длинные слова не ломают кнопки, бейджи и меню.
6. **Доступность (WCAG AA):**
   - контраст не ниже 4.5:1;
   - видимый фокус с клавиатуры;
   - подписи у всех полей;
   - у иконок-кнопок есть `aria-label`;
   - статусы не передаются только цветом.
7. **Единообразие:** одинаковые отступы (шаг 4px), одинаковые заголовки страниц (`page-head`: заголовок + подзаголовок + действия справа), одинаковые карточки и одинаковое положение кнопок в модалках (отмена слева, главное действие справа).

## 6. Задача В — новые функции (нарисовать как готовые экраны)

**Учёба**
1. **Карточки для запоминания (flashcards):** колоды по курсам, режим повторения (переворот карточки, кнопки «Не помню / Сложно / Помню / Легко»), прогресс колоды, AI-генерация карточек из материала.
2. **Календарь дедлайнов:** месяц и неделя, цвета по типу (задание, тест, урок), боковая панель «Ближайшие», напоминания.
3. **Режим фокуса (Pomodoro, довести):** полноэкранный таймер с Ух в режиме «фокус», выбор длительности, XP за учебное время, статистика за неделю.
4. **Сертификат курса:** красивый PDF-шаблон (A4, альбомный) с QR-кодом для проверки подлинности + страница «Проверить сертификат».

**Геймификация**

5. **Ежедневные задания:** 3 задания в день (например, «Пройди 1 тест», «Повтори 10 карточек», «Учись 25 минут»), прогресс по каждому, награда за все три.

8. **Командные соревнования групп:** рейтинг групп (IT-2101 против IT-2102), вклад каждого студента, недельный сезон.

**AI**

9. **AI-объяснение ошибки** прямо после ответа в тесте (раскрывающийся блок под вопросом).
10. **AI для преподавателя:** генерация вопросов теста из загруженной лекции (выбор количества и сложности → список вопросов с правкой и удалением → добавить в тест).
11. **AI-сводка для преподавателя** на дашборде: «5 студентов отстают по теме JOIN» + кнопка «Отправить им материалы».

**Общение**

12. **Обсуждения:** вопросы и комментарии под материалом урока, ответы преподавателя выделены, отметка «Решено».
13. **Telegram-уведомления:** экран подключения бота (QR или кнопка), выбор событий.

## 7. Задача Г — полная админ-панель

Сейчас у админа 5 экранов: обзор, пользователи, роли, курсы, настройки. Нужна полноценная панель управления платформой. Боковое меню админа сгруппируй по разделам:

**Обзор**
1. **Дашборд:**
   - KPI-плитки: всего пользователей, активные сегодня и за неделю, новые регистрации, курсы, пройденные тесты, средний балл; у каждой плитки тренд ↑↓ к прошлому периоду;
   - графики: рост пользователей, активность по часам и дням (heatmap), распределение по ролям, топ-курсы;
   - выбор периода: 7 / 30 / 90 дней / свой диапазон;
   - блок «Требует внимания»: курсы на модерации, жалобы, заблокированные, ошибки системы — с быстрыми ссылками.
2. **Аналитика обучения:** воронка «зарегистрировался → начал курс → прошёл тест → завершил курс», вовлечённость по группам и факультетам, самые сложные темы (по ошибкам в тестах), удержание по неделям (когортная таблица).

3. **Пользователи (довести):**

6. **Импорт пользователей из CSV/Excel:** шаблон для скачивания, загрузка, сопоставление колонок, предпросмотр с ошибками в строках, итог (создано / пропущено / ошибки).

**Контент**

**Геймификация**

**Система**

22. **Настройки платформы (довести):** название, логотип, цвета акцента (в рамках палитры), языки по умолчанию, регистрация (открыта / по приглашению / только с почтой домена вуза), режим техработ.
23. **Состояние системы:** база данных, хранилище, AI, почта — зелёный, жёлтый или красный статус, время ответа, последние ошибки.

## 8. Задача Д — отдельная вкладка «Игры» 🎮

Новый раздел в боковом меню студента — **«Игры»** (иконка `gamepad-2`), между «Достижения» и «Лига». Цель: учиться через короткие игры на 2–5 минут по материалам курсов. Игры дают XP и двигают ежедневные задания и лигу. Стиль тот же, что у всего сайта (фиолетовая палитра, Ух как ведущий), но ярче и динамичнее.

**8.1. Главная страница «Игры» (хаб)**
- Шапка: «Игровая зона» + Ух в настроении «ликует», XP за игры сегодня и лимит, кнопка «Случайная игра».
- Блок «Игра дня» (большая карточка с бонусом ×2 XP и таймером до смены).
- Сетка карточек игр: обложка-иллюстрация, название, длительность, сложность (1–3 звезды), курс или тема, лучший результат, бейдж «Новая» / «Популярная».
- Фильтры: по курсу, по типу (на скорость / на память / на логику / с друзьями), по длительности.
- Блок «Продолжить» (незавершённые игры) и «Недавно играли».
- Мини-рейтинг недели по играм.

**8.2. Сами игры** (для каждой — экран правил, игровой экран, экран результата)
1. **Викторина на скорость:** 10 вопросов по курсу, таймер на каждый вопрос, комбо за правильные ответы подряд, подсказки за XP (50/50, «спросить Ух»).
2. **Найди пару (мемори):** перевёрнутые карточки «термин ↔ определение», счётчик ходов и время.
3. **Собери код / пазл:** перетащить строки кода или SQL-запроса в правильном порядке (подсветка ошибок).
4. **Правда или ложь:** утверждения появляются по одному, свайп влево или вправо (на телефоне) или кнопки, 60 секунд.
5. **Кроссворд и филворд** по терминам курса.
6. **Поиск ошибки:** фрагмент кода или текста, нужно нажать на строку с ошибкой.
7. **Дуэль 1 на 1:** вызов одногруппника, одинаковые вопросы, кто быстрее и точнее. Экраны: поиск соперника / приглашение, ожидание, игра с прогрессом соперника вживую, результат.
8. **Командная битва групп:** группа против группы, общий счёт, вклад каждого.
9. **Босс-битва:** в конце модуля «босс» с полоской здоровья; каждый правильный ответ наносит урон, ошибка отнимает жизни у игрока (сердечки).

**8.3. Общие игровые элементы (дизайн-компоненты)**
- **Игровая шапка:** таймер (JetBrains Mono, краснеет на последних 10 секундах), жизни-сердечки, счёт, комбо-множитель, пауза.
- **Обратная связь:** верно — зелёная вспышка, +очки улетают вверх, Ух радуется; неверно — короткая тряска, Ух грустит, показ правильного ответа.
- **Экран паузы и выхода** («Прогресс не сохранится»).
- **Экран результата:** звёзды (1–3), счёт, XP с анимацией, новый рекорд, место в рейтинге, кнопки «Ещё раз» / «Другая игра» / «Поделиться», конфетти (уже есть в системе).
- **Таблица рекордов** по каждой игре: за неделю / за всё время / среди группы.
- **Звук:** иконка вкл/выкл в шапке (по умолчанию выключен).
- **Доступность:** режим без таймера, крупный шрифт; анимации отключаются при `prefers-reduced-motion`; на телефоне все игры управляются касанием.

**8.4. Для преподавателя**
- Вкладка **«Игры курса»** в курсе: выбрать, какие игры доступны, задать набор вопросов или карточек, AI-генерация вопросов для игры из материала.
- Статистика: кто играл, средний результат, самые сложные вопросы в играх.
- Запуск **«живой игры на паре»:** преподаватель показывает код комнаты на проекторе, студенты подключаются с телефонов, на экране таблица лидеров в реальном времени (как Kahoot).

**8.5. Для админа**
- Управление играми: включить или выключить, XP-награды, дневной лимит XP за игры (чтобы не «фармили»), игра дня, жалобы на вопросы.

**8.6. Состояния**
- Нет игр по курсу (Ух предлагает другой курс).
- Достигнут дневной лимит XP («Можно играть дальше, но без XP»).
- Нет соперника для дуэли.
- Соперник вышел.
- Потеря соединения в живой игре.

## 9. Формат результата

Для **каждого** экрана дай:
1. **Название и роль** (кто видит), место в навигации.
2. **Макет** для компьютера (1280) и телефона (375), в светлой и тёмной теме.
3. **Список компонентов:** сначала существующие из раздела 2, а новые — с описанием (размеры, отступы, цвета через токены).
4. **Все состояния** (пусто / загрузка / ошибка / успех / disabled).
5. **Тексты интерфейса на трёх языках** (RU / KZ / EN).
6. **Где появляется Ух** и с каким настроением.
7. **Микроанимации**, если нужны, с вариантом для `prefers-reduced-motion`.

## 10. Ограничения

- Только цвета и токены из раздела 2. Новый цвет допустим только как оттенок существующего и с объяснением.
- Только Inter / JetBrains Mono и иконки Lucide.
- Не использовать стоковые фото людей — только иллюстрации в стиле Ух, иконки и градиентные обложки.
- Не добавлять тяжёлых библиотек. Графики — в текущем стиле (фиолетовый, бирюзовый, розовый).
- Никаких «заглушечных» текстов вроде «Lorem ipsum» — реальные примеры (курсы по SQL, Laravel, REST API, алгоритмам; группы IT-2101 и т. п.).
