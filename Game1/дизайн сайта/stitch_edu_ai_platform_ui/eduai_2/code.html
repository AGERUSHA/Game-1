check_circle Правильный ответ:

«LEFT JOIN возвращает абсолютно ВСЕ записи из левой таблицы, дополняя их NULL из правой таблицы, если совпадения нет.»

auto_awesome AI-Тьютор Афина: Анализ ошибки и рекомендация
Синтез правила

Вы перепутали семантику: строгое совпадение с обеих сторон отсекает строки без связей — это поведение классического INNER JOIN. Если вам нужно сохранить список всех клиентов (даже тех, кто ещё не совершил ни одной покупки), всегда используйте LEFT JOIN.

-- Верная конструкция выборки всех пользователей и их покупок:
SELECT users.name, orders.total
FROM users
LEFT JOIN orders ON users.id = orders.user_id;
Рекомендовано повторить: Лекция 4.2 «Анатомия JOIN запросов»
