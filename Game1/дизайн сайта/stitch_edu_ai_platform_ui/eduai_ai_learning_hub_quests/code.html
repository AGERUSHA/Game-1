Не могу понять, почему запрос с LEFT JOIN возвращает NULL для некоторых строк?

14:24 done_all
ВЫ
psychology
school Разбор логики SQL только что

При LEFT JOIN сохраняются все записи левой таблицы, даже если в правой таблице нет подходящих совпадений по условию ON.

SQL Query Snippet

SELECT users.name, orders.id

FROM users

LEFT JOIN orders ON users.id = orders.user_id;

-- Если у пользователя нет заказов, orders.id станет NULL

Совет ментора: Если вам нужны только строки, у которых строго есть связь, замените оператор на INNER JOIN.
